# FUP Exponent Explorer

A desktop Python application for exploring finite-stage fractal uncertainty principle (FUP) exponents numerically. It generates Cantor digit-set pairs, computes the operator norms of their restricted discrete Fourier transforms, and displays the results in an interactive scatter plot.

The explorer supports both uniform (isotropic) and coordinate-dependent (anisotropic) scaling.

## Features

- **Two scaling modes:** explore uniform scaling bases or sweep combinations of different scaling factors across coordinates.
- **Adjustable experiments:** choose the dimension, scaling range, Cantor iteration stage, and maximum digit-alphabet size.
- **Exact or sampled searches:** control how many alphabets and alphabet pairs are considered.
- **Interactive graph:** hover to inspect a point, click to pin its details, and click again to cycle through overlapping points.
- **Hilbert–Schmidt comparison:** display a reference line and the difference between each computed exponent and that reference.
- **Optional highlighting:** outline pairs that pass the program's blockwise rigidity check.
- **Import and export:** save results as CSV, reopen previous results without recalculation, and export plots as PNG or PDF.
- **Windows executable:** package the application using PyInstaller.

## Installation

Requires **Python 3.10 or later**, **NumPy**, **Matplotlib**, and **Tkinter**.

Install the Python packages:

```bash
python -m pip install numpy matplotlib
```

Tkinter is included with most standard Windows Python installations. On some Linux systems, it must be installed separately (for example, `sudo apt install python3-tk` on Ubuntu/Debian).

## Run

Save `fup_interactive_explorer.py` to a folder and run:

```bash
python fup_interactive_explorer.py
```

On Windows, you can also use:

```powershell
py fup_interactive_explorer.py
```

Choose parameters and click **Generate**. The application computes results in a separate thread so the window stays responsive. **Cancel** stops the run after the current matrix calculation finishes and displays the completed results.

## Controls

| Setting | Description |
| --- | --- |
| **Scaling mode** | Choose `isotropic` or `anisotropic`. |
| **Dimension d** | Number of coordinates in the digit sets. |
| **Min scaling / Max scaling N** | Range of integer scaling factors to examine (minimum 2). |
| **Max \|A\|,\|B\|** | Largest allowed size of either digit alphabet. |
| **Stage k** | Number of Cantor-set construction iterations. |
| **Max alphabets / size** | Sampling limit for alphabets of each size. |
| **Max pairs / base** | Sampling limit for alphabet pairs per scaling configuration. |
| **Max matrix entries** | Skips calculations with restricted Fourier matrices exceeding this size. |
| **Random seed** | Makes sampled searches reproducible. |
| **Exact alphabet enumeration** | Enumerate all eligible alphabets, after removing translation duplicates. |
| **Exact unordered pairs** | Examine all eligible unordered pairs among the generated alphabets, subject to the matrix-size limit. |
| **Mark HS-rigidity obstruction pairs** | Highlight pairs identified by the built-in rigidity check. |

In **isotropic mode**, each coordinate uses the same scaling factor, and the program explores every base in the selected range. In **anisotropic mode**, the program explores distinct combinations of coordinate scaling factors from that range. It avoids redundant coordinate permutations and omits combinations where all factors are equal.

Alphabets are generated by the program rather than entered manually. This version supports **diagonal integer scaling**.

## Understanding the graph

Each point represents one evaluated pair of digit alphabets at the selected iteration stage.

- **Horizontal axis:** average density of the two alphabets.
- **Vertical axis:** computed finite-stage FUP exponent.
- **Solid black line:** Hilbert–Schmidt reference exponent.
- **Dashed black line (isotropic mode only):** additional comparison curve.
- **Outlined circles:** pairs identified by the optional rigidity check.

Higher points relative to the solid black line indicate a greater improvement over the Hilbert–Schmidt estimate for that particular numerical calculation.

Hover over a point to see the scaling factors, alphabets, cardinalities, density values, exponent, operator norm, and comparison values. Click a point to keep its information visible in the **Selected point** panel. If multiple pairs appear in the same location, click repeatedly to cycle through them. Click an empty area of the plot to clear the selection.

Use the Matplotlib toolbar beneath the graph to zoom, pan, or reset the view. The **Computation log** shows progress and skipped calculations.

## Exporting and loading results

**Save CSV** exports the evaluated pairs and their numerical results, including the scaling configuration, alphabet definitions, iteration stage, operator norm, exponent, and highlighting flags.

**Import CSV** opens a previously exported file and recreates the interactive graph without rerunning the numerical calculations. Older isotropic CSV files in the supported format can also be imported. All rows in an imported file must have the same dimension and iteration stage.

**Save PNG** exports the plotted figure. The same dialog also offers **PDF** output.

## Build a Windows executable

Install PyInstaller:

```powershell
py -m pip install pyinstaller numpy matplotlib
```

Then run:

```powershell
py fup_interactive_explorer.py --build-exe
```

The executable will be created at:

```text
dist\FUP_Explorer.exe
```

Run this command on Windows to create a Windows executable.

## Performance notes

Larger dimensions, digit alphabets, and iteration stages can dramatically increase the number and size of matrices. The program uses dense matrices and singular-value decomposition, so some experiments may consume substantial memory and processing time.

For exploratory runs, leave the exact-enumeration options disabled and use the sampling and matrix-entry limits. Increase these limits when a more extensive search is needed. Calculations use floating-point arithmetic, and the plotted exponents are specific to the selected finite iteration stage.
